# Input data

| File | Content | Source in manuscript |
|---|---|---|
| `image_descriptors.csv` | Image-derived descriptors from one photomicrograph per species (n = 1, no replication). PD packing density; OSF open-space fraction (1 - PD); RG geometric regularity; CO structural continuity; LI layering index (excluded from scoring); ED edge density. | Table 3 |
| `literature_scores.csv` | Literature-derived ordinal scores (0-10). SC structural compactness; TO tissue organization; TR tissue robustness; MC morphological complexity; WH water-holding capacity. Rubric in Table S1. | Table 5 |

Rows are keyed by species name. The analysis never relies on row order.
Raw photomicrographs are available from the corresponding author on request.
